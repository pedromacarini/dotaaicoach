# Vozes locais do DotaIACoach

Substitua os arquivos `.txt` pelos áudios com o mesmo nome e extensão `.wav`:

```text
stack.txt       -> stack.wav
pull.txt        -> pull.wav
power-rune.txt  -> power-rune.wav
wisdom-rune.txt -> wisdom-rune.wav
lotus.txt       -> lotus.wav
roshan.txt      -> roshan.wav
tormentor.txt   -> tormentor.wav
```

Formato recomendado: WAV PCM, mono, 44.1 kHz ou 48 kHz.

Os `.txt` são placeholders intencionais. Enquanto o `.wav` não existir, o app usa a síntese de voz local pt-BR do Windows.
