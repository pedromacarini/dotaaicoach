# Dota 2 Brasil Overlay

O **Dota 2 Brasil Overlay** é uma ferramenta avançada projetada para melhorar a experiência de jogo dos fãs de Dota 2 no Brasil. Com uma interface elegante e recursos personalizáveis, o overlay oferece informações vitais em tempo real, tornando o jogo mais envolvente e estratégico.

![Dota 2 Brasil Overlay](https://github.com/seu_usuario/dota2-overlay-brasil/blob/main/docs/images/overlay_screenshot.png)

## Recursos Principais

- **Overlay em Tempo Real**: Visualize informações cruciais durante o jogo, como habilidades, itens, duração de magia e muito mais.
- **Paridade Completa**: Mantemos a paridade com as versões oficiais para garantir que você tenha todas as funcionalidades disponíveis.
- **Notificações Personalizáveis**: Configure notificações para alertar sobre eventos importantes durante a partida.
- **Item Timing**: Acompanhe o timing de itens para otimizar suas estratégias de jogo.
- **Draft Advisor**: Conselhos de draft para ajudar na escolha das herois e itens.

## Como Usar

### 1. Clonar o Repositório
```bash
git clone https://github.com/seu_usuario/dota2-overlay-brasil.git
cd dota2-overlay-brasil
```

### 2. Instalar Dependências
```bash
npm install
```

### 3. Configurar Variáveis de Ambiente
- Crie um arquivo `.env` no diretório raiz do projeto e adicione as variáveis necessárias conforme descrito abaixo.

### 4. Executar o Projeto
```bash
npm start
```

### 5. Executar os Testes
```bash
npm run test
```

## Variáveis de Ambiente
Exemplo de `.env`:
```env
REACT_APP_API_KEY=seu_chave_api
REACT_APP_ENV=dev
```
