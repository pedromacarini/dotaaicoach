# Escopo técnico da biblioteca

| Domínio | Versão 0.2 | Próximos passos |
|---|---|---|
| Heróis e atributos | Gerador e navegador de dados | filtros, localização, vínculos de funções |
| Itens / custo / componentes | Gerador e navegador | árvore de receitas, sugestão manual |
| Habilidades / custos / cooldowns | Gerador e navegador | contextualização por nível |
| Habilidades por herói e talentos | Relações do OpenDota | interface de árvore de talentos e aprendizado |
| Neutros e histórico de patches | Inventários auxiliares | cronogramas conforme regras publicadas |
| Dissipações e status | Extensão prevista, sem dados próprios do Aura | taxonomia validada em fonte livre |
| Rotas de farm e mapa | Extensão prevista | banco manual configurável e algoritmos próprios |
| Cronograma, timings de objetivos | Extensão prevista | documentação oficial das regras para cada patch |
| Estatísticas em partida | GSI local existente | calcular tendências com dados do jogador |
| Recomendações por posição | Biblioteca: partidas profissionais, skills e inventários finais via OpenDota | integrar ao overlay e ampliar amostra/cache persistente |

**Atenção:** nomes de arquivos presentes no inventário do Aura são evidência de componentes arquiteturais, não prova de comportamento nem permissão para copiar conteúdo. A implementação de todos os itens é independente.
