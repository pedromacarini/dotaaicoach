# Contribuindo

Este é um projeto comunitário independente. Seja bem-vindo para contribuir com documentação, testes, acessibilidade, segurança e melhorias de interface.

## Antes de abrir um PR

1. Não envie código, texturas, imagens, sons, material proprietário nem arquivos extraídos do Aura/Dota2Brasil ou do jogo.
2. Não introduza leitura de memória, automação de ações do jogo, técnicas anticheat/anti-VAC, remoção de DRM, informações ocultas nem coleta de dados de terceiros.
3. Toda sugestão de nova fonte de dados precisa especificar documentação, licença, privacidade e modo de jogo afetado.
4. Teste `npm run build` e `npm run test` localmente.
5. Não cole o arquivo `gamestate_integration_*.cfg` gerado pelo painel: ele contém um token privado.

## Planejamento

Abra uma issue com: comportamento esperado, fonte de dados, riscos competitivos, desenhos da interface próprios e passos para reproduzir. Recursos de análise pós-partida têm prioridade sobre assistências em tempo real controversas.
